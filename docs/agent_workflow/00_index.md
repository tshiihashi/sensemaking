# Agentの解析・知識整理・レポート作成の運用案

複数データ・複数手法を扱うAgentについて、既存の文献調査から作業手順と保存方法を提案する。**全体は応用案であり、Agentや読者に対する効果は未検証。** skillの実装ではない。

| [02_review_and_design_decisions.md](02_review_and_design_decisions.md) | 既存調査に対して薄かった点、修正の理由、複数データ・複数手法の架空例での机上照合 |

課題との対応は、見逃しに対する確認範囲・選択条件の記録、情報過多に対する段階的な構造化と本文選択、横断理解に対する条件・依存・関係の整理、複数解釈に対する仮説比較と判断の分岐である。既存の入れ子構成、説明的なファイル名、Markdown本文部品の再利用も維持する。

次に必要なのは実際の解析成果物での試行。記録・改訂の負担、重要な関係の発見と例外の保持、読者の理解、掲載先での画像・リンク解決は未検証である。02は既存資料との照合、03は2026-11-07の補完検索・原典照合を含む。候補探索はSynthesis内に置き、新しい必須ファイル層は追加していない。

[候補発見・表現変更・検証への接続に関する4論文の詳細調査](../insight_discovery/00_index.md)では、Foresight、Russellら、DataSite、EXHYTEの具体的な仕組み、採用範囲、架空例を整理した。原典の内容とAgentへの未検証の応用案を分けている。運用案§5・§6へ必要時の具体化を反映し、操作・様式を目的に応じて省略・統合・順序変更できる方針を§1へ明記した。
