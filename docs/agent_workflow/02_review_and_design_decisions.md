# ワークフロー案のレビューと修正理由

## 1. レビューの結論と範囲

**保存と追跡の設計は具体的だったが、結果を見て次の判断・解析へ進む指示が相対的に薄かった。** 2026-11-06のレビュー前版には、観察と解釈の分離、比較条件、根拠の依存、仮説比較、原資料への参照が既にあった。これらを「欠けていた」とは扱わない。一方、「何を確認したら十分か」「何が起きたら分類や判断を変えるか」が短い一般論に留まり、保存項目を埋めても肝心の横断理解が進まない余地があった。

文献の量を指示の長さへ比例させる必要はない。今回の修正では、**契機 → 操作 → 判断 → 残す成果物**を具体化し、既存の保存先を使った。入れ子の知見管理、説明的な名前、本文部品の再利用は維持している。

対象はSoK、Sensemaking、生物医学、読者理解の既存調査と設計資料。以下は **[既存調査に基づく設計判断・未検証]**。リンク先の原典整理・二次情報・応用案の区別を引き継ぐ。新規検索、原典の再照合、解析コードの実行、Agentの比較試験、人による理解評価は行っていない。

## 3. 複数データ・複数手法を含む架空例での机上照合

**すべて説明用の設定。実データ・実測値・医学的結論ではない。** この例で実施したのは、与えた設定に対して手順が必要な区別を表現できるかの机上照合であり、Agentが自律的に発見・保存できることの試験ではない。

### 入力と保持する観察

問いQ-101を「条件Cで見られた変化を、細胞内の状態変化と細胞組成の変化のどちらで説明できるか」とする。

| 入力・観察 | 与えられた設定 | 手順に従って残すもの |
| --- | --- | --- |
| S-101、F-101 | scRNA-seqデータAの集計結果で遺伝子群Gが増加 | 対象条件、集計単位、元表位置、方向。原因は含めない |
| S-101、F-102 | 同じAからのpathway・CCI・GRN出力に、説明候補に関係する結果がある | 方法別の観察と関係の意味。共通入力・前処理・使用DBを記録し、独立データの追加と数えない |
| S-102、F-103 | 別コホートBの細胞種内比較では統計的に有意でない。採取時点がAと違い、効果量・区間は未確認 | 「明確な差を示す根拠が未確認」。効果なし、Aへの決定的反証とはしない。時点差を残す |
| S-101、F-104 | Aでは細胞種の割合も変わる | 組成による説明と整合する観察。細胞内変化の併存は否定しない |
| S-103 | 文献が別条件で機序Mを報告する | 背景・説明の前提。今回の条件に適用する接続は未確認 |
| 未測定 | 今回の条件ではタンパク質・介入結果がない | 確認範囲に未測定と明記。陰性結果として扱わない |

H-101「細胞内状態の変化が寄与」、H-102「細胞組成の変化が寄与」を保持する。両者は併存し得るため、排他的な二択に固定しない。F-101とF-102だけでは寄与を識別できず、F-104だけでH-101を棄却しない。各手法が実際に何を推定するかは案件の設定から確認する。

### 次の操作と判断の分岐

最初の候補は、Aの対象細胞種・独立した観測単位・必要なメタデータを確認し、可能なら細胞種内の比較と組成を考慮した集計を行うこと。これは元データに対する追加確認で、独立な追試ではない。

| 追加確認の結果 | 更新する判断 | なお言えないこと |
| --- | --- | --- |
| 対象細胞種内でも比較可能な変化が残る | 組成だけの説明では不十分な可能性。H-101の検討を進める | 機序Mや因果を実証したとはいえない |
| 組成を考慮すると変化が小さくなる | H-102と整合する。推定の不確かさも確認する | 細胞内変化が全くないとはいえない |
| 試料対応や必要な条件が不明 | この確認では識別できない。必要情報を未解決事項へ | 解析を実施しただけで比較可能になったとはいえない |

Bとの比較は採取条件と推定結果を確認してから行う。揃えられなければ条件別に示す。新たな介入等が依頼範囲外なら、必要な確認と再開条件を示して止める。説明を確定するために追加実験を実施済みと書かない。

### 表現とレポートへの反映

手法別のファイルだけでは関係を追いにくいため、横断整理を「現象×細胞種・採取条件」に組み替える。元のFと正本は維持し、比較表から参照する。図の候補は、集計結果と細胞種内比較、細胞組成、A/Bの条件差。未実施の解析は空の結果図にせず、必要な確認として示す。

現時点の入口文は、例えば次の範囲に留める。

> この架空例では、データAの集計で遺伝子群Gの増加と細胞組成の変化が観察された。同じAを使う複数手法の結果は、独立した追試ではない。細胞内状態と組成の寄与はまだ分けられず、条件の異なるBと未測定のタンパク質・介入結果からも機序Mは確定できない。

「複数手法で機序Mが確認された」「Bでは有意でないので機序はない」という要約を作らない。読者確認の課題は、独立な入力と手法数の違い、Bが反証と決まらない理由、次の確認で変わる判断を説明できるかとする。

### 照合結果と限界

机上では、共有根拠、条件差、非有意、未測定、併存する説明、次の操作の分岐、比較軸の変更を既存の保存先で記述できた。旧案にも保存欄はあったが、修正案ではそれを埋める操作と判断の契機を明示できている。

この例では数値計算、実ファイル間の追跡、訂正の伝播、図の生成・掲載は試していない。網羅性、作業負担、実際のAgentの判断品質、読者理解の改善は未検証。次は[運用案§8](01_workflow_and_files.md#8-完了条件と今後の検証)の同一入力・予算での試行に進み、使われない記録欄は削る。
