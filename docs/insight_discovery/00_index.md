## この調査で得た結論

[調査に基づく判断] 追加する価値が高いのは、保存ファイルを増やすことより、次の操作を明確にすることである。

1. **候補の型と探索条件を決める。** 「関連を探す」を、同じ対象の方向不一致、部分集団だけの変化など、検索・計算できる操作にする。
2. **局所探索の後に全体へ戻る。** 関心のある経路だけを追わず、未確認領域と選別から外れた結果を確認する。
3. **説明に収まらない結果を、表現変更の材料にする。** 分類を埋めるだけでなく、集計単位・比較軸・問いを見直す。
4. **仮説に次の確認を結び付ける。** 実行入力、競合する予測、出力、解釈の更新条件を記す。

これらは本リポジトリ向けの **[応用案・未検証]**。統計的に目立つパターン、科学的な説明、読者にとって重要な情報は別である。4本を組み合わせても、未知の重要関係を漏れなく発見できるとはいえない。
