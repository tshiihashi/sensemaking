# AI解析レポートを読む人の理解・納得感・認知負荷：補完調査

調査日：2026-11-06（日本時間）。対象は、AI agentが作成した解析レポートを受け取る人の読解・根拠確認・判断である。[元の4課題](../../data_analysis_reporting_challenges.md)を変更せず、既存の[SoK整理](../systemization_of_knowledge/00_index.md)と[Sensemaking調査](../sensemaking/00_index.md)に、読者を直接扱う研究を補う。

## 今回の答え

[調査に基づく判断] **読みやすさ、理解の正確さ、主観的な納得感、根拠に見合った信頼、読解・検証の負担を別々に評価する必要がある。** 平易な説明や図表の注釈は有望だが、説明・引用の存在が誤った回答への依存を増やす条件もある。採用判断の根拠と適用条件は[読解研究](01_reading_and_presentation.md)、[信頼・検証研究](02_trust_and_verification.md)に示す。

現時点では、**読者の予備知識に説明を合わせ、主張の近くに比較条件・根拠・重要な限界を置き、詳細へ戻れる構成**を第一候補とする。階層化そのものを今回の論文群が一括して検証したわけではない。具体的な編集手順は[設計比較](03_report_design.md)、読者による確認方法は[評価案](04_evaluation_protocol.md)を参照する。

## 用語と確認状態

- **納得感**：ここでは「説明を受け入れられるという主観」と「根拠・推論・限界を説明できること」を分ける。単一の標準尺度を意味しない。
- **読みやすさ**：主観的な読みやすさ、言語の表面的な簡単さ、実際の理解成績を区別する。
- **認知負荷**：内容の難しさと、情報を探す・対応付ける負担を区別する。検証に必要な思考まで一律に減らすことは目標にしない。
- `[原典の実証結果]` は当該研究自身の結果、`[原典の整理]` は著者の説明、`[応用案]` / `[調査に基づく判断]` はこのリポジトリ向けの提案、`[架空例による確認]` は説明用データの整合確認である。

研究論文12本とNASA公式資料1件を対象にした目的別調査であり、システマティックレビューではない。人を対象にした短い英語の要約・QA・学習・判断課題が多い。複数結果・複数解釈を含む日本語のAgentレポートの性能保証には使わない。既存SoKの個別研究すべてを原著照合済みに変更したものでもない。
