- 公開PDFは外部へのリンクとして記録し、このリポジトリには複製していない。リンクの確認と、PDFのローカル保存は別である。

## 3. 検索方法

提示された11論文について、完全タイトル、著者名、DOIを使ってWeb検索し、出版社・原著者・所属機関・会議の公開資料を優先した。目的は既知候補の照合と、今回の不足を補う文献の探索であり、データベースを横断した網羅的収集ではない。

代表的な検索語は以下のとおり。検索順・全ヒット数を記録したPRISMA型の手続きではない。

| 検索の目的 | 実際に使った検索語の例 | 結果・採用判断 |
| --- | --- | --- |
| 主張単位の構造化 | `"Sensemaking Tools for Understanding Research Literatures" Uren` | KMiと出版社書誌へ。P03を採用、本文未確認を明示 |
| 元資料との接続 | `"Linking Unstructured Evidence to Structured Observations" filetype:pdf` | TU Wienの掲載版PDFを発見、P04を採用 |
| 全体のプロセス | `"The sensemaking process and leverage points" pdf` | P02の原著ミラーを確認 |
| 観察と知見の区別 | `"Knowledge generation model for visual analytics" pdf Sacha` | 研究グループ公開原稿へ。P05を補足として採用 |
| 曖昧さ | `"Designing for Ambiguity in Visual Analytics" pdf` | VIS公開原稿と2024年巻号を照合、P06を採用 |
| 形式化の負担 | `"Formality Considered Harmful" Shipman Marshall 1999` | 大学公開PDFと出版社を照合、P08を優先 |
| 導入と知識統合 | `"discourse graphs" "2021" knowledge synthesis`、`"Steps Towards an Infrastructure for Scholarly Synthesis"` | P12の2024年プレプリントを追加。2021年の紹介だけに依存しない |
| 論証の受容規則 | `"On the acceptability of arguments" Dung 1995 pdf` | 原著§2を確認、P13を用途別として追加 |
| 来歴・領域・UIの補足 | 各完全タイトル＋`pdf`、`2012`、`2008`等 | P07、P09〜P11を確認し、用途に応じた位置づけにした |

検索結果にはResearchGate、個人ノート、論文紹介サービス等もあったが、それらの解説を原著の実証結果の根拠には採用していない。原著の内容をミラーで読んだ場合は、本文の著者と配布元を区別した。
