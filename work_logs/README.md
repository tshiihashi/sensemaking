# 作業履歴

調査・設計・文書化・実装について、何を行い、何を判断し、何が残ったかを記録する。ファイル差分だけでは分からない目的や確認結果を、成果物へのリンクとともに残す。

## 記録方法

1. 作業開始時に、日付順で直近の `YYYY-MM-DD.md` と、今回に関係する過去の記録を読む。
2. 作業完了・中断時に、日本時間の当日ファイルへ [テンプレート](TEMPLATE.md) のエントリを追記する。ファイルがなければ、先頭に `# YYYY-MM-DD 作業履歴` を書いて作成する。
3. 同日に複数の作業があれば、`## HH:MM — 作業名` の見出しで分ける。同時刻に重なる場合は識別できる作業名を付ける。日付をまたいだ場合は記録時点の日付を使い、必要なら実施期間を記す。
4. 成果物には、このディレクトリからの相対リンクを使う。確認の実施結果と、今後行う予定を分ける。
5. 再開・訂正・追加判断は新しいエントリとして追記し、対象の記録をリンクする。他の作業者のエントリを上書きしない。

履歴ファイルは日付名で一覧できるため、日々の索引更新や専用ツールは不要。`TEMPLATE.md` は参照用で、必ずしも全項目を長く埋める必要はない。該当しない確認や残課題には「なし」などを記す。

過去作業を後から記録する場合は、実施時刻を推測せず「遡及記録」と明記する。履歴は要約であり、調査本文や会話全文、内部思考、機密情報の保存先にはしない。
